The [BOM post](/blog/homelab-bom) selected specific hardware. Before committing to three or five nodes, everything gets validated on a single machine. Buy one, test it, then scale.

Validation breaks into two stages:

<Callout title="Validation stages" variant="summary">
  1. **Hardware Validation** — CentOS Stream 10 live boot. Prove every component works: storage tiers, NIC detection, PCIe negotiation, SMART health, concurrent I/O, and network throughput. No installation, no disk writes — just a repeatable checklist.
  2. **OKD SNO Deployment** — Install OKD 4.20 as a Single Node cluster on the validated hardware. DNS, installer configuration, platform-specific workarounds, and first workloads. *(coming soon)*
</Callout>

Start with the hardware validation to confirm the components before any platform touches the disk.
